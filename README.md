# BatterySmart BaaS homepage

Throwaway static Home screens for **3W battery rental**. English only. Mobile viewport **412×892**.

Nine Home states, each a real HTML page: ready, fault, due, overdue, first-run, paid-up, grace, subscribe, lease.

Nav stays Home / My Wallet / Plan Details. Wallet and Plan are stub pages so those labels do not 404. MOSFET fail is a ride-fail. Subscribe is a label chip, not a button. No DEV strip.
